# Portfólio — Matheus Macêdo Felicio

Portfólio Full Stack responsivo com modo claro/escuro, navegação por seções, animações progressivas e integração com a API pública do GitHub.

**Site:** https://tteukkkk.github.io/portfolio-matheus/

## Projetos em destaque

- [AgendaFlow SaaS](https://tteukkkk.github.io/portfolio-matheus/projetos/agendaflow-saas.html) — agendamentos multiempresa, equipes, reservas e assinaturas configuráveis.
- [DevFlow](https://tteukkkk.github.io/portfolio-matheus/projetos/devflow.html) — Kanban colaborativo, tarefas, permissões, WebSockets e issues do GitHub.
- [FinTrack](https://tteukkkk.github.io/portfolio-matheus/projetos/fintrack.html) — finanças pessoais, orçamentos, metas, importação e relatórios.

As imagens são capturas dos frontends renderizados em ambiente local com dados fictícios; os backends não são hospedados neste repositório. Os códigos dos projetos serão publicados em repositórios próprios.

## Tecnologias

HTML semântico, CSS, JavaScript e API pública do GitHub. Sem build obrigatório ou dependências JavaScript.

## Desenvolvimento

Abra `index.html` ou use um servidor HTTP estático local (`python -m http.server 8000`). Para publicar, envie os arquivos para a branch `main` e configure **Settings → Pages → Deploy from a branch → main → /(root)**.

## Acessibilidade e movimento

Há link para pular a navegação, foco de teclado, cores compatíveis com ambos os temas, alternância de tema persistente e redução de movimento em `prefers-reduced-motion`.
